## 🚀 Featured Projects

### 🏥 1. Radiotherapy Analytics Dashboard (Desktop Version)
A comprehensive BI solution aimed at optimizing operational workflows and clinical monitoring for oncology treatments.

- **Key Features:**
  - Real-time monitoring of linear accelerator workloads (Elekta and Varian).
  - Waiting list tracking and compliance with the SUS target (<15 days).
  - Multidimensional analysis across healthcare providers, tumor sites, and radiation techniques (VMAT, SBRT, IMRT).
- **Technologies:** Power BI, Advanced DAX, Power Query, Dark Mode UX/UI.
- 🔗 **[Explore Desktop Dashboard Online](https://laossa-luiz.github.io/radiotherapy-analytics-dashboard/)**

---

### 📱 2. Radiotherapy Executive Dashboard (Mobile Version)
A mobile-first adaptation focused on usability, portability, and rapid decision-making on smaller screens for clinicians and department heads.

- **Key Features:**
  - Touch-optimized *Mobile-First* layout for swift navigation.
  - Core KPI cards for active patients, treatment sessions, and DQA metrics.
  - Integrated tracking table with quick patient search capabilities.
- **Technologies:** Power BI Mobile Layout, DAX, Mobile UX Design.
- 🔗 **[Explore Mobile Dashboard Online](https://laossa-luiz.github.io/radiotherapy-mobile-dashboard/)**
